# Prompt v1 — resumo de bula

Responda à pergunta do usuário usando os trechos de bula recuperados. Seja breve
e use linguagem simples.

## Limitação identificada

A versão não obrigava a citar a fonte, não explicava como tratar instruções
maliciosas contidas no OCR e não definia uma resposta segura quando a busca não
encontrasse evidência suficiente.
